 # CREATE AN  ACCOUNT IN AWS SET UP A ROOT USER AND AN IAM USER 
  ## AIM
       To Create an Account in AWS Set up a Root user and an IAM user.
## PROBLEM STATEMENT
   Create an AWS account and configure a secure IAM user with appropriate permissions to ensure safe access to AWS resources without using the root account for daily tasks.

## ALGORITHM
 ### Steps 1: Create an AWS account.
 ### Steps 2: Log in using the Root User account.
 ### Steps 3: Open the AWS IAM Management Console.
 ### Steps 4: Create a new IAM user and configure the IAM user with console access.
 ### Steps 5: Assign the required permissions to the IAM user and review the configuration and create the IAM user.

## COMMANDS
No command-line commands were used in this experiment. All tasks were performed using the AWS Management Console.
